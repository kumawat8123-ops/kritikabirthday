# Kratika Birthday Website

A birthday surprise made with vanilla HTML, CSS, and JavaScript. Open `index.html` in a browser to view it.

## Personalize it

Edit `SITE_CONFIG` at the top of `app.js` to change the sender name, birthday details, intro, reasons, wishes, letter, and optional music file.

## Photos

The 16 gallery photos are in `images/` and referenced from `index.html`. Keep the filenames in the HTML in sync with the files in that folder.

## Music

Place an MP3 in `music/` and set its path in `SITE_CONFIG.music.file`. If the file is unavailable, the page plays a small synthesized tune instead.
